# Bundler
---

- Bundler tell what it does by it's name, it bundles.
- Bundler loads every neccesary code which need the ownwork to run before any user defined code
- If User Wants to Load a general application code, he can put the file in `bundle/` directory, and include it like other files are included
- Understanding exactly what it loads up:

## autoload.php

- Located at: `appDirectory/vendor/autoload.php`.
- It is generated by command `composer run setup`.
- If you want to know how composer works deeply, go through it's documentation [Here](https://getcomposer.org/doc/).
- For simple understanding, remember that it automatically loads every file in your `appDirectory/app/` directory, so that you don't have to manually load each new created Controller or Model Files.
- If not found and you spin the server, you will see a page saying to setup the application using `composer run setup`.

## Environment.php

- Located at: `appDirectory/bundle/Environment/Environment.php`.
- This file is responsible for loading and setting Environmental variables like checking if DEV_ENV variable is `true` in `.env`.
- It's also further loads up `appDirectory/bundle/Environment/DotEnvironment.php` which actually loads the `.env` file into `$_ENV` array.
- You can specify Environment related settings here.

## HelperFunction.php

- Located at: `appDirectory/bundle/HelperFunction.php`.
- This file contains global helper functions which are used by OwnWork application itself, and also can be used anywhere further this step, not before it (It may break flow of execution like `undefined function error`).
- Some Helper Function are like:
	- `approot()`: Provide the directory path of app root like `/home/username/ownwork`.
	- `out(string $data)`: Return string escaped for HTML special characters(uses htmlspecialchars() function under hood).
		> `$data` - string to be escaped

	- `view(string $string, array $args = [])`: Instantly Call a view and pass arguments as associative array
		> `$string` - view file path relative to `approot() . "/resources/views/"`.

		> `$args` -  Pass Optional Arguments as array, which will use `extract()` function to change it in to key-value pairs to variable = value
	- `comp(string $name, array $args = [], string $dir = "")`: Call Component stored at  `approot() . "/resources/views/component/"`
		> `$name` - file path relative to `approot() . "/resources/views/component/"`.

		> `$args` -  Pass Optional Arguments as array, which will use `extract()` function to change it in to key-value pairs to variable = value

		> `$dir` -  Optional argument to change directory to find component.

- Many More Functions can be found and defined in HelperFunction.php, take a look at it to see what more it contains.

## Handler.php

- Located at: `appDirectory/bundle/ErrorHandler/Handler.php`.
- Special Error Handler which will show up when error arrives in your app.
- Introduced in `v2.0`, it shows every php error with proper readable and intuitive user interface.
- It also logs details of error in `appDirectory/storage/error.log`
- It also displays stack trace while providing code snippet of call stack involved in current error.
- Also displays app related information like env variables.
